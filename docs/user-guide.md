# 使用手册

适用版本：yt-dlp Studio v1.1.1。

[返回项目首页](../README.md) · [高级选项参考](advanced-options.md)

## 1. 界面结构

应用提供四个主要页面：

| 页面 | 主要用途 |
| --- | --- |
| 新建下载 | 输入链接，选择媒体类型、画质、格式和保存位置 |
| 下载列表 | 查看所有任务，筛选状态，取消、重试及查看详情 |
| 高级选项 | 配置播放列表、字幕、网络与访问参数 |
| 设置 | 调整外观、默认目录，检测或更新下载引擎，退出应用 |

页面切换不会清空本次会话中已经输入的链接与下载方式。重新启动应用后，主题、目录及高级配置会从本地设置恢复；链接输入和媒体格式选择不作为完整会话恢复。

## 2. 创建视频下载

1. 打开“新建下载”。
2. 输入完整 HTTP 或 HTTPS 链接。多条链接应逐行填写，一次提交 1 至 50 条。
3. 如需预览，单击“解析链接”。
4. 选择“视频”。
5. 设置视频画质及视频格式。
6. 确认保存位置。
7. 单击“开始下载”。

应用会保存当前配置，将全部有效链接加入队列，然后跳转到“下载列表”。同一批次中的任务使用提交时的相同选项。如果该批次存在无效链接，应先修正输入后再提交。

解析属于可选步骤。输入多条链接时，“解析链接”仅检查第一条；“开始下载”会提交全部链接。解析阶段显示标题、时长、发布者或站点信息及可用分辨率摘要，不会展开并下载整个播放列表。

## 3. 选择画质与视频格式

### 3.1 画质

可选项包括最佳画质、最高 2160p、1440p、1080p、720p 和 480p，默认最高 1080p。

“最高”表示分辨率上限。选择 1080p 不会将低清源文件提升至 1080p；原站提供的格式、音视频组合及网络情况仍会影响最终结果。对于没有分辨率信息的媒体直链，程序允许继续尝试下载。

### 3.2 格式

| 选项 | 行为 |
| --- | --- |
| MP4 | 优先选择 H.264/AAC，按需合并或重新封装为 MP4 |
| MKV | 请求使用 MKV 作为合并或重新封装的目标容器 |
| 自动 | 由 yt-dlp 根据可用媒体及处理流程确定容器 |

容器格式与编码方式并不相同。MP4 扩展名不保证任何播放器都能解码其中的视频。应用不会为了保证统一编码而强制重新编码所有视频。

## 4. 创建音频下载

选择“仅音频”，然后设置输出格式：

| 格式 | 说明 |
| --- | --- |
| MP3 | 常用有损音频格式 |
| M4A | 常用于 AAC 等音频内容的容器 |
| FLAC | 无损压缩格式，通常需要较多存储空间 |
| WAV | 常见音频容器，输出体积可能较大 |

应用会选择可用的最佳音频来源，并按需调用 FFmpeg 处理。将有损来源转换为 FLAC 或 WAV，不会恢复原始来源中已经丢失的细节。

## 5. 保存位置与文件命名

保存位置可以直接输入绝对路径，也可以单击“更改”，使用 Windows 文件夹选择器选择目录。取消文件夹对话框不会修改现有设置。

默认位置是软件目录下的 `downloads`。在“新建下载”和“设置”页面修改的默认目录会同步保存。已提交任务保留提交时的输出目录，不随之后的默认设置变化。

文件名模板由媒体标题和站点媒体 ID 组成，并进行 Windows 文件名兼容处理。应用启用保留现有文件的下载策略。已有文件、部分下载文件及后处理过程的最终行为由 yt-dlp 与实际站点共同决定。

“打开下载文件夹”打开当前填写的保存目录；任务中的“打开所在文件夹”打开该任务记录的输出目录，不是自动选中某一个具体文件。目录尚不存在时，程序会尝试创建它。

## 6. 队列与任务状态

当前队列默认按提交顺序逐个执行。高级选项中的分片并发数控制单个下载内部的媒体分片，不代表同时执行多个队列任务。

| 状态 | 含义 | 可采取的主要操作 |
| --- | --- | --- |
| 等待中 | 已加入队列，尚未开始 | 取消、查看详情 |
| 正在下载 | 正在传输媒体内容 | 取消、查看详情 |
| 正在处理 | 正在合并、转换或执行其他后处理 | 取消、查看详情 |
| 正在取消 | 已请求结束下载进程 | 等待状态更新 |
| 已完成 | 下载进程已成功结束 | 查看详情、打开目录、移除记录 |
| 下载失败 | 下载或后处理未成功 | 查看错误、重试、打开目录、移除记录 |
| 已取消 | 用户取消了任务 | 重试、打开目录、移除记录 |
| 已中断 | 上次后台退出时任务尚未完成 | 重试、打开目录、移除记录 |

下载列表提供“全部”“进行中”“已完成”“未完成”筛选。“未完成”包含失败、取消及中断的任务。

应用尚未提供通用的“暂停/继续”按钮。取消后的重试会重新排队；能否利用部分文件继续下载取决于站点、协议和已有文件情况。

## 7. 进度与任务详情

下载任务可显示百分比、速度和预计剩余时间。部分来源没有总大小，界面无法据此计算可靠百分比。

音轨与视频可能分别下载，因此进度可能多次从较低数值开始。播放列表显示的是当前媒体文件的进度，而非整个列表的加权总进度。进入“正在处理”后，即使下载百分比已经达到 100%，也应等待最终完成状态。

“查看任务详情”显示该任务近期的原始输出、错误信息及已记录文件路径。当前后台为每个任务保留最多 100 条近期日志，每条最多 4,000 个字符，详情窗口不是完整、无限保留的命令行输出归档。

## 8. 取消、重试与移除记录

- 取消等待任务：将其移出本次执行队列并标记为已取消。
- 取消正在执行的任务：请求结束该下载进程及其相关媒体处理进程。
- 重试：重新排队，清理原错误与近期日志，继续使用原任务的配置。
- 移除记录：仅从应用历史中移除记录，不删除下载文件。

如果需要修改画质、输出位置、代理或字幕配置后重试，应以新配置重新创建任务。直接单击“重试下载”不会将当前高级设置覆盖到旧任务。

## 9. 外观设置

主题包括简约白、午夜黑、暖沙和雾松绿，默认简约白。选择主题后立即应用并自动保存。当前版本采用实色界面，不提供毛玻璃或背景模糊开关。

“紧凑下载列表”用于降低列表项的显示密度，不改变下载速度、队列策略或文件格式。

设置页面显示“正在保存”“已保存”或保存失败提示。离开应用前，应确认需要保留的设置已保存成功。

## 10. 系统托盘、退出与重复启动

最小化或关闭窗口时，应用收起到系统托盘，下载后台继续运行。若未看到图标，请查看任务栏隐藏图标区域。

托盘左键及右键菜单“打开控制台”恢复已有窗口。“打开控制台”在当前桌面版中表示打开应用主窗口，不是打开命令行终端。

完全退出应使用托盘“退出”或“设置 → 退出应用”。存在下载、排队、解析或更新操作时，程序会提示先结束相关操作。

再次启动已在运行的应用时，程序显示通知并取消新启动。此时请通过任务栏或托盘打开原窗口，不需要反复运行安装包或启动程序。
