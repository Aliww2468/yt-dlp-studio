# 高级选项参考

适用版本：yt-dlp Studio v1.1.1。

[返回项目首页](../README.md) · [使用手册](user-guide.md)

## 1. 总开关与配置生效时间

“启用高级选项”默认关闭。关闭时，相关输入控件不可用，任务采用基础默认参数；已保存的高级配置不会自动作用于新任务。

开启总开关后，配置仅在创建新任务时写入任务记录。修改配置不影响已排队或正在执行的任务。对旧任务执行“重试”时，仍使用该任务原有配置。

基础默认参数仍包含失败重试、写入媒体信息等内置行为。关闭高级总开关不等于关闭所有 yt-dlp 参数。

## 2. 播放列表

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| 下载整个播放列表 | 关闭 | 开启后允许 yt-dlp 展开并处理播放列表 |
| 下载范围 | 空 | 为空表示不通过该参数限制列表范围 |

范围采用正整数及简单区间格式，例如：

| 示例 | 含义 |
| --- | --- |
| `1-10` | 第 1 至第 10 项 |
| `1,3,5` | 第 1、第 3 和第 5 项 |
| `1-3,8,10-12` | 多个区间与单项组合 |

当前输入校验不支持 yt-dlp 的所有列表切片语法。范围仅在播放列表开关启用时传递。列表项目的实际可见性、编号及可下载状态由站点和 yt-dlp 决定。

解析按钮始终采用不展开播放列表的检查方式。解析预览不代表已经验证整个列表的全部项目。

## 3. 字幕与附加内容

| 选项 | 默认值 | 生效条件及行为 |
| --- | --- | --- |
| 下载字幕文件 | 关闭 | 请求站点提供的普通字幕 |
| 包含自动生成的字幕 | 关闭 | 请求站点提供的自动字幕 |
| 字幕语言 | `zh.*,en` | 在启用普通字幕或自动字幕后使用 |
| 将字幕嵌入视频 | 关闭 | 需启用至少一种字幕下载，且为视频模式 |
| 保存封面图片 | 关闭 | 将可用封面作为附加文件保存 |
| 写入媒体信息 | 开启 | 请求将可用的媒体信息写入输出文件 |

字幕语言使用逗号分隔，例如 `en`、`zh.*,en`。其中 `zh.*` 用于匹配中文相关语言标识。输入总长度上限为 200 个字符，具体可用语言取决于源站。

“自动生成的字幕”指下载源站已有的自动字幕，不表示应用在本机执行语音识别或生成翻译。未提供字幕的媒体不会因为开启此选项而自动产生字幕。

字幕是否可以嵌入，受字幕格式、输出容器和 FFmpeg 支持情况影响。封面保存也不等同于自动将封面嵌入所有音视频容器。

## 4. 下载限速

下载限速默认为空，不主动传入限速值。支持数字及可选的 K、M、G 后缀，允许小数。

| 输入示例 | 说明 |
| --- | --- |
| `500K` | 使用 yt-dlp 的 K 单位限速表示法 |
| `2M` | 使用 yt-dlp 的 M 单位限速表示法 |
| `1.5M` | 含小数的限速值 |

单位由 yt-dlp 按其参数规则解释，属于传输字节速率表示，不应直接等同于运营商标称的比特带宽。该参数影响下载传输，不限制 FFmpeg 后处理的 CPU 使用量。

## 5. 分片并发

默认值为 1。界面提供 1、2、4、8 四个选项，后台接收范围为 1 至 8 的整数。

此项仅对支持分片下载的来源产生作用。提高数值可能改善部分来源的传输效率，也可能触发站点限速或增加网络负担。它不改变应用顺序执行队列任务的设计。

## 6. 代理地址

代理地址默认为空。为空时，应用不主动向 yt-dlp 传入代理参数，是否使用系统或进程环境中的代理由下载工具及运行环境决定。

支持以下协议：

- HTTP
- HTTPS
- SOCKS5
- SOCKS5H

格式示例：`http://127.0.0.1:7890`。示例端口仅表示格式，不说明用户电脑已存在该代理服务。

高级代理只作用于相关解析或下载任务，不等于修改 Windows 全局代理，也不直接配置安装器、NuGet 或 GitHub CLI 的网络连接。

代理配置会保存在本机设置和任务选项中。若地址包含认证信息，分享配置或日志前应删除相关敏感字段。

## 7. 浏览器登录状态

默认值为“不读取”。可选择 Chrome、Edge 或 Firefox。

选择后，yt-dlp 会尝试读取所选浏览器的 Cookie，并将可用登录状态用于请求相关站点。应用未提供在界面中输入账号密码的通用站点登录流程。

读取失败可能与浏览器数据库占用、加密机制、配置位置或 Windows 用户权限有关。可以先在浏览器确认目标站点已登录，再根据错误信息处理。该能力不保证适用于全部浏览器版本和站点。

## 8. 失败重试次数

默认值为 5，允许 0 至 20 的整数。当前实现将此值同时用于下载重试和分片重试。

较高重试次数会延长确定任务失败所需的时间，不会解决永久失效链接、缺少访问权限或不受支持的媒体类型。

## 9. 配置示例

### 9.1 下载指定范围并保存中英文字幕

1. 开启高级总开关。
2. 开启播放列表下载。
3. 将范围设为 `1-10`。
4. 开启普通字幕下载；需要源站自动字幕时，同时开启自动字幕。
5. 将语言设为 `zh.*,en`。
6. 返回新建下载页面，以这些选项创建新任务。

### 9.2 使用已有浏览器登录状态

1. 在浏览器中确认可以访问目标媒体。
2. 在高级选项中选择对应浏览器。
3. 如有需要，设置已存在的代理服务地址。
4. 重新解析链接或创建新任务。
5. 若失败，查看任务详情中的实际错误，不仅依据页面预览判断登录是否成功。

这些示例说明配置方法，不代表相应站点或链接已经通过实机验证。
