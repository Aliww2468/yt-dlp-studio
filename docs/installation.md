# 安装、升级与卸载说明

适用版本：yt-dlp Studio v1.1.1。本文面向 Windows x64 用户。

[返回项目首页](../README.md)

## 1. 选择发行版

### 1.1 普通安装版

普通安装版是轻量联网安装器。发行文件本身包含应用界面、后台源码、桌面程序及组件检测脚本，不预装 .NET、Node.js、yt-dlp 或 FFmpeg 二进制组件。

安装器将检查本机环境，复用可用组件，并下载缺少的组件。对于环境已经齐全的电脑，不会重复复制或下载这些依赖。对于环境不完整的电脑，首次安装所需下载量可能明显大于安装器本身。

### 1.2 便携版

便携版包含完整应用目录以及 .NET、Node.js、yt-dlp、FFmpeg 和 FFprobe。使用时必须完整解压，不能仅复制主程序 EXE。

便携版仍使用系统 WebView2 Runtime，因此不等同于可以在任何离线电脑上直接运行。将便携版转移至另一台电脑前，应确认目标电脑具有 WebView2 Runtime。

### 1.3 支持的平台

当前正式发行文件适用于 Windows 10/11 x64。项目未提供 Windows x86、原生 Windows ARM64、macOS 或 Linux 安装包，也未将这些平台列为已验证环境。

## 2. 普通安装流程

1. 从 [Releases](https://github.com/Aliww2468/yt-dlp-studio/releases/latest) 下载名称包含 `Setup.exe` 的文件。
2. 运行安装器，阅读安装位置和组件处理说明。
3. 单击“安装”。安装器首先释放应用文件，然后检查依赖环境。
4. 在安装窗口中查看各组件的检测结果。已有组件显示为可复用，缺少组件进入下载和安装流程。
5. 等待全部组件通过检查。完成后，安装器显示完成信息，并提供“打开软件”按钮。

当前安装器使用固定的当前用户目录：

```text
%LOCALAPPDATA%\Programs\yt-dlp Studio
```

该路径通常位于当前 Windows 用户的本地应用数据目录下。当前版本不提供自定义安装路径输入框。应用文件安装至当前用户目录；安装 .NET 等系统组件时，Windows 可能请求管理员授权。

安装过程会创建开始菜单快捷方式和当前用户的卸载记录。桌面快捷方式不是当前安装器的默认输出。

## 3. 组件检测与补齐规则

| 组件 | 检测方式 | 缺少时的处理方式 |
| --- | --- | --- |
| .NET Desktop Runtime 8 x64 | 检查标准 Program Files 下的 dotnet，确认 Desktop 与 NETCore 的 8.0 运行时均存在 | 从 Microsoft 发布元数据获取安装器，校验 SHA-512 和签名后执行 |
| WebView2 Runtime | 检查 Microsoft 文档指定的当前用户与计算机注册表版本记录 | 下载 Microsoft Evergreen 引导安装器，验证签名后执行 |
| Node.js | 执行版本及架构检查，要求 22+、x64 | 下载 Node.js 24 LTS 的 Windows x64 归档，校验后提取 node.exe |
| yt-dlp | 执行版本与帮助检查，确认支持 JavaScript 运行时参数 | 从 yt-dlp 官方 GitHub Release 下载并校验可执行文件 |
| FFmpeg 与 FFprobe | 在同一目录中执行两个程序的版本检查 | 从 yt-dlp/FFmpeg-Builds 下载并校验归档，提取两个程序 |

Node.js、yt-dlp 和 FFmpeg 的候选路径按以下顺序检查：

1. 当前软件目录中的 `bin`。
2. `dependencies.json` 中上次记录的路径。
3. 当前进程继承的系统 `PATH` 中可找到的程序。

其中，只有通过相应检查的候选项才会被采用。FFmpeg 与 FFprobe 必须位于同一目录。当前检测不等同于逐项验证所有编码器、字幕类型和站点功能。

对于安装在非标准位置的自定义 .NET 环境，当前检测可能无法识别；此时安装器可能继续补齐标准 .NET Desktop Runtime。仅安装普通 .NET Runtime、仅安装其他主版本，均不保证满足当前桌面程序的要求。

下载至软件目录的 Node.js、yt-dlp、FFmpeg 和 FFprobe 存放在 `bin` 中。复用的外部路径写入 `dependencies.json`，不会复制整套共享组件至软件目录。

## 4. 下载进度与失败处理

安装窗口提供当前处理步骤及下载字节进度。若服务器提供文件总大小，进度信息同时显示已下载大小和总大小；执行系统安装器时可能只显示正在安装。

下载使用 HTTPS。Node.js、yt-dlp、FFmpeg 和 .NET 文件按照相应分发方提供的散列值校验。执行 Microsoft 组件安装器前，程序还会检查数字签名。

发生网络错误、校验失败或系统组件安装失败时：

1. 保留安装窗口中的错误信息。
2. 检查网络连接、可用磁盘空间及 Windows 安装提示。
3. 重新运行安装器，或在当前窗口重试。
4. 已经安装且通过检测的组件通常可以直接复用。

当前版本不保证大文件下载可以从中断位置继续。临时下载目录会在该轮处理结束时尝试清理。失败后可能保留已释放的应用文件，不能以目录已存在判断安装成功。

## 5. 便携版部署

1. 下载 `portable.zip`。
2. 解压至具有写入权限的目录，例如用户自行管理的软件目录。
3. 确认 `yt-dlp Studio.exe`、`bin`、`public`、`lib` 和后台脚本保持原有相对位置。
4. 双击主程序。
5. 若提示缺少 WebView2，按照 [Microsoft WebView2 下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 提供的方式安装 Runtime。

不建议从 ZIP 压缩包预览窗口直接运行程序。该方式可能只临时释放部分文件，导致组件、界面资源或数据目录不完整。

## 6. 校验发行文件

在下载目录打开 PowerShell，执行：

```powershell
Get-FileHash -LiteralPath '.\yt-dlp-Studio-1.1.1-win-x64-Setup.exe' -Algorithm SHA256
Get-FileHash -LiteralPath '.\yt-dlp-Studio-1.1.1-win-x64-portable.zip' -Algorithm SHA256
```

将输出的散列值与同一 Release 的 `SHA256SUMS.txt` 对照。文件名和版本必须一致。上述两个校验条目仅对应安装器和便携归档；另外附加的文档包具有独立的校验文件。

## 7. 升级与修复

### 7.1 升级安装版

1. 从托盘或设置页面完全退出软件。
2. 确认不存在尚未完成的下载、解析或更新操作。
3. 备份 `data` 目录及需要保留的下载文件。
4. 运行新版安装器，安装到默认目录。
5. 启动后检查主题、默认保存位置和历史记录。

仅关闭窗口会保留后台，不能代替完全退出。安装器会检查目标目录中的程序和部分二进制文件是否仍被占用。

### 7.2 升级便携版

建议将新版完整解压至新目录，退出旧版后再迁移必要数据。可以复制 `data/settings.json` 和 `data/jobs.json`，并将下载文件移动或保留在原来的位置。

任务记录及保存位置可能包含绝对路径，迁移后不会自动重写为新目录。对于已记录的任务，修改默认保存位置也不会自动改变原任务的路径。需要新的路径或选项时，应重新创建任务。

### 7.3 修复外部组件路径

安装版复用的外部组件被卸载、移动或损坏后，软件可能无法启动或执行任务。请重新运行安装器，检查并更新依赖路径。不要将原电脑的 `dependencies.json` 直接视为另一台电脑上的有效配置。

“更新 yt-dlp”仅更新下载引擎，不更新 GUI、Node.js、.NET 或 FFmpeg。GUI 更新仍通过新版发行包完成。

## 8. 卸载与保留数据

安装版可从 Windows 应用设置或安装目录中的 `Uninstall.exe` 卸载。卸载前须完全退出软件。

卸载器依据安装清单删除应用管理的文件，移除开始菜单快捷方式及卸载记录。它保留下载文件和个人设置，也不卸载复用的系统级 .NET、WebView2 或其他外部组件。卸载完成后，软件目录可能因保留数据或空目录而继续存在。

便携版不注册常规安装记录。停用便携版时，应先退出程序，再自行备份并处理完整目录；删除目录会同时影响其中保存的个人数据和下载文件。
